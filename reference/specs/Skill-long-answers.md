# Common questions, tailored answers
Online job application forms will sometimes contain open-ended questions. This is done to gain insight that the resume and cover letter alone do not provide. The problem for job applicants is that writing meaningful, impactful prose takes time. Project research is clear on the value of time to submission.
## User Stories
- [[US-open-ended-questions-forms]]
- [[US-open-ended-questions-interviews]]
- [[US-open-ended-questions-evaluation]]
## Success
Success is measured quantitatively and qualitatively:
- An average reduction in time to submission is the duration from when a job description is staged to when its status switches to "applied"; initial measurement of three days.
- [[🧑 Applicant]] rocks that interview and maybe just maybe it was because the [[🧑 Recruiter]] or [[🧑 Team Lead]] made an informed decision (note: scope is limited to the first metric re: rocking it).
## Features
- answers tailored to the dossier
- one file per application
- user-managed templates
## Requirements
- Output is in a format that is easily accessible
- Answers can be copipasta'd without characters that will make the form submission throw up
## Constraints
- The strongest resource is likely composed of interview transcripts, which cannot be counted upon in frequency
