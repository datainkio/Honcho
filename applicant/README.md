# Applicant

As the agent tasked with running the pipeline, I need to retrieve the data that the pipeline expects in order to run.
As a job candidate, I want to iterate on pipeline inputs so that I can find the optimal configuration for my needs and expectations.

## cover-letters/

The files in this folder supply the static content for the rendered cover letter, as well as defining the locations (aka slots) where generated content is expected.

## criteria/

The files in this folder determine how searches are defined and conducted for the implemented datasources.

## dossiers/

A dossier is the collection of all known information about a candidate.

## questions/

Files supplying answers to life's - or online job applications - commonly asked questions.

## resumes/

The files in this folder supply the static content for the rendered resume, as well as defining the locations (aka slots) where generated content is expected.

## rules/

Rule files direct how content is generated.

## styles/

Simple typographic styling for consistency across documents.
