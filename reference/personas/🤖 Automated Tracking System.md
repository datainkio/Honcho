# Automated Tracking System
Software, not a person. Receives the application before anyone reads it.
Turns it into a structured record the recruiter can search and sort.
## Decides
"Can I read this, and does it pass the filters set for this role?"
## Attention
Instant and literal. Reads text only. Sees no design.
## Looks for
Plain text it can parse, in a standard file format.
Conventional section headings and dates.
The posting's exact terms.
Answers to the screening questions.
## Rules out
A failing answer to a screening question. This is the only outright rejection.
Text in images, columns, or tables. It garbles these rather than rejecting them.
## Moves it forward by
Putting a complete, searchable record in front of the recruiter.
