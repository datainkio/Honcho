# skills

The five skills are the entry points to this repo:

## job-setup

`/job-setup` builds an install's profile, truth rules and criteria;

## job-retrieval

`/job-retrieval` runs one retrieval session;

## resume-tailoring, cover-letter-writing, interest-statement

`/resume-tailoring`, `/cover-letter-writing` and `/interest-statement` build a posting's application package. Each `SKILL.md` is the only operational authority for its task; the specs in `pipeline/specs/` hold rationale only.
